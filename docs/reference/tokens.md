# Token reference

## Sources of truth

| Artifact | Location | Generated by |
|---|---|---|
| `tokens.yaml` | `packages/fw_core/tokens.yaml` | Hand-maintained |
| `tokens.g.dart` | `packages/fw_core/lib/src/tokens/` | `fw_token_gen` (build_runner) |
| `tokens.json` | `packages/fw_core/lib/src/tokens/tokens.json` | `fw_token_gen` (W3C DTCG 2025.10) |

56 described tokens. The JSON uses `$value` / `$type` / `$description`
leaves; token names are semantic and brand-free, so AI agents and design
tools can consume them as an API.

## Regenerating

```bash
cd packages/fw_core
dart run build_runner build
```

Generated files are committed so tests pass without running build_runner.
`token_export_test` pins all 56 leaves: JSON parses, DTCG leaf shape,
key sets match the Dart API, value parity.

## Key scales

- Spacing: `FwSpace` s0–s24 (8px base, 4px exception) + `FwSpaceAlias`
- Color: `FwColorPrimitives` → `FwColors` → component `ThemeExtension`s
- Type: `FwTextRole` (14 roles)
- Motion: `FwMotionSpeed` xs–xl + `FwSpring`
- Elevation: `FwElevation` 0–5 · Grid: `FwGrid` viewport classes
- Haptics: `FwHaptics` tap/confirm/error/selection
